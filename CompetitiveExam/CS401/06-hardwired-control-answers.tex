\begin{enumerate}
\item[\textbf{Q1}] \textbf{(C).} Every hardwired control signal is a Boolean function of an opcode line $D_i$ \emph{and} a step line $T_j$ together --- neither alone identifies both ``which instruction'' and ``which step.''

\item[\textbf{Q2}] \textbf{5.} $\lceil \log_2 25 \rceil = 5$ (4 bits address only 16 codes, insufficient for 25; 5 bits address 32).

\item[\textbf{Q3}] \textbf{(C).} \texttt{SC} counts through control-step numbers and the step decoder expands the count into one-hot $T_i$ lines, exactly as a modulo-$n$ counter plus decoder would.

\item[\textbf{Q4}] \textbf{64.} $2^6 = 64$.

\item[\textbf{Q5}] \textbf{(C).} Hardwired control is \emph{faster} per step than microprogrammed control (pure combinational logic, no memory read) --- this is an \emph{advantage} of hardwired control, not a disadvantage, making it the correct choice for "NOT a disadvantage."

\item[\textbf{Q6}] \textbf{(B).} The OR-of-products pattern exists precisely because a control signal can be needed by more than one instruction at the same step number; each instruction that needs it contributes its own $(D_i \cdot T_j)$ term to the same shared equation.
\end{enumerate}
