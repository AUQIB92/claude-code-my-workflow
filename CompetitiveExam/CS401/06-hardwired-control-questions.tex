\noindent Each question carries 1--2 marks. MCQ = single correct option; NAT = Numerical Answer Type.

\begin{enumerate}
\item[\textbf{Q1}] \textit{[Original, GATE-pattern]} \textbf{[MCQ, 1 mark]} In a hardwired control unit, every control signal is generated as a function of:
\begin{enumerate}
  \item[(A)] Opcode decoder lines only
  \item[(B)] Step decoder lines only
  \item[(C)] Both the opcode lines and the step lines together
  \item[(D)] Neither --- signals are read from a stored table
\end{enumerate}

\item[\textbf{Q2}] \textit{[Original, GATE-pattern]} \textbf{[NAT, 1 mark]} An instruction set architecture has 25 distinct instructions. The minimum number of bits required in the instruction's opcode field to encode all of them is \rule{1.5cm}{0.4pt}.

\item[\textbf{Q3}] \textit{[Original, GATE-pattern]} \textbf{[MCQ, 1 mark]} A sequence counter (\texttt{SC}) together with a step decoder, as used to generate one-hot control-step signals in a hardwired control unit, is functionally most similar to:
\begin{enumerate}
  \item[(A)] A program counter driving an instruction cache
  \item[(B)] An instruction register holding the current opcode
  \item[(C)] A modulo-$n$ counter feeding an $n$-output decoder
  \item[(D)] A stack pointer
\end{enumerate}

\item[\textbf{Q4}] \textit{[Original, GATE-pattern]} \textbf{[NAT, 1 mark]} A hardwired control unit's sequence counter is implemented with 6 bits. The maximum number of distinct control steps it can address is \rule{1.5cm}{0.4pt}.

\item[\textbf{Q5}] \textit{[Original, GATE-pattern]} \textbf{[MCQ, 2 marks]} Which of the following is \textbf{NOT} a disadvantage of hardwired control relative to microprogrammed control?
\begin{enumerate}
  \item[(A)] Difficult to modify after the chip is fabricated
  \item[(B)] Design/verification complexity grows with instruction-set size
  \item[(C)] Slower per control step than microprogrammed control
  \item[(D)] Requires re-deriving Boolean equations whenever the ISA changes
\end{enumerate}

\item[\textbf{Q6}] \textit{[Original, GATE-pattern]} \textbf{[MCQ, 2 marks]} For a control signal shared by two instructions at the same control step, e.g.\ $Z_{\text{in}} = (D_{\text{ADD}} \cdot T_2) + (D_{\text{SUB}} \cdot T_2)$, the OR operation reflects the fact that:
\begin{enumerate}
  \item[(A)] \texttt{ADD} and \texttt{SUB} must execute simultaneously
  \item[(B)] $Z_{\text{in}}$ must be asserted whenever \emph{any} instruction whose state table lists it at that step is running
  \item[(C)] $Z$ is a shared bus line, not a register
  \item[(D)] The equation is redundant and can be simplified to a single term
\end{enumerate}

\end{enumerate}
