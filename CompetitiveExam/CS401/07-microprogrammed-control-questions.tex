\noindent Each question carries 1--2 marks. MCQ = single correct option; NAT = Numerical Answer Type.

\begin{enumerate}
\item[\textbf{Q1}] \textit{[GATE CS 2002 Q2.7, 2 marks --- verified, see provenance note above]} \textbf{[MCQ, 2 marks]} Horizontal microprogramming:
\begin{enumerate}
  \item[(A)] does not require use of signal decoders
  \item[(B)] results in larger sized microinstructions than vertical microprogramming
  \item[(C)] uses one bit for each control signal
  \item[(D)] all of the above
\end{enumerate}

\item[\textbf{Q2}] \textit{[GATE CS 2004 Q67, verified --- GATEOverflow V3 p.78]} \textbf{[MCQ, 2 marks]} The microinstructions stored in the control memory of a processor have a width of 26 bits. Each microinstruction is divided into three fields: a micro-operation field of 13 bits, a next-address field ($X$), and a MUX-select field ($Y$). There are 8 status bits in the input of the MUX. How many bits are there in the $X$ and $Y$ fields, and what is the size of the control memory in number of words?
\begin{enumerate}
  \item[(A)] 10, 3, 1024
  \item[(B)] 8, 5, 256
  \item[(C)] 5, 8, 2048
  \item[(D)] 10, 3, 512
\end{enumerate}

\item[\textbf{Q3}] \textit{[GATE CS 1996 Q2.25, verified --- GATEOverflow V3 p.77]} \textbf{[MCQ, 1 mark]} A microprogrammed control unit is required to generate a total of 25 control signals. Assume that during any microinstruction, at most two control signals are active. The minimum number of bits required in the control word to generate the required control signals is:
\begin{enumerate}
  \item[(A)] 2
  \item[(B)] 25
  \item[(C)] 10
  \item[(D)] 12
\end{enumerate}

\item[\textbf{Q4}] \textit{[GATE CS 1997 Q5.3, verified --- GATEOverflow V3 p.77]} \textbf{[MCQ, 1 mark]} A micro-instruction is to be designed to specify: (a) none or one of the three micro-operations of one kind, and (b) none or up to six micro-operations of another kind. The minimum number of bits in the micro-instruction is:
\begin{enumerate}
  \item[(A)] 9
  \item[(B)] 5
  \item[(C)] 8
  \item[(D)] None of the above
\end{enumerate}

\item[\textbf{Q5}] \textit{[Original, GATE-pattern]} \textbf{[MCQ, 1 mark]} Compared to horizontal microprogramming, vertical microprogramming:
\begin{enumerate}
  \item[(A)] requires no decoder between control memory and the datapath
  \item[(B)] produces wider control words
  \item[(C)] requires a decoder, adding to the delay before control signals become valid
  \item[(D)] cannot encode mutually exclusive control signals
\end{enumerate}

\item[\textbf{Q6}] \textit{[Original, GATE-pattern]} \textbf{[MCQ, 1 mark]} In a microprogrammed control unit, the component that loads the microprogram counter (\texttt{MPC}) with the starting microaddress of the instruction currently in \texttt{IR} is the:
\begin{enumerate}
  \item[(A)] Control memory
  \item[(B)] Mapping unit
  \item[(C)] Sequence counter
  \item[(D)] Arithmetic logic unit
\end{enumerate}

\item[\textbf{Q7}] \textit{[Original, GATE-pattern]} \textbf{[MCQ, 2 marks]} Arranged from fastest to slowest per control step, the typical ordering of the following control-unit implementations is:
\begin{enumerate}
  \item[(A)] Vertical microprogrammed $>$ Horizontal microprogrammed $>$ Hardwired
  \item[(B)] Hardwired $>$ Horizontal microprogrammed $>$ Vertical microprogrammed
  \item[(C)] Horizontal microprogrammed $>$ Hardwired $>$ Vertical microprogrammed
  \item[(D)] Hardwired $>$ Vertical microprogrammed $>$ Horizontal microprogrammed
\end{enumerate}

\end{enumerate}
