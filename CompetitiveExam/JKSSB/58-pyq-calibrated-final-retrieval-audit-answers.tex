\noindent\textbf{Provenance:} All 20 items are original JKSSB-pattern
questions (\textit{[Original]}); none reproduces an official paper item.
\begin{enumerate}[label=\textbf{Q\arabic*.}, leftmargin=*]
\item \textbf{A.} ISP is Internet Service Provider. B, C, and D rearrange
  the same words into forms the exam never uses.
\item \textbf{C.} The bit is the smallest unit of data; 8 bits make a byte.
  A byte (A), a nibble (B), and a word (D) are all larger.
\item \textbf{C.} F5 starts the slide show from the beginning; Shift+F5
  starts from the current slide. F7 (A) is spell check, F9 (B) and F1 (D)
  have other roles.
\item \textbf{B.} A formula must start with the equals sign. A leading plus
  (A), percent (C), or hash (D) does not begin a formula.
\item \textbf{C.} MICR reads magnetic ink characters. OCR (A) reads printed
  text, OMR (B) reads marks, and a QR code (D) is a printed matrix symbol.
\item \textbf{C.} ICs arrived in the third generation; microprocessors
  arrived in the fourth. A, B, and D name the wrong generations.
\item \textbf{A.} Android is the open-source mobile operating system. B
  describes a proprietary system, C a shareware trial, and D a firmware
  loader --- none is the open-source mobile OS.
\item \textbf{B.} The BIOS initialises hardware and loads the operating
  system. A device driver (A) is software serving one device, a compiler (C)
  translates code, and a spreadsheet (D) is an application.
\item \textbf{B.} The at-sign separates the user name and the domain name.
  A swaps in host wording, C invents sender/recipient parts, and D names
  message fields.
\item \textbf{D.} A Select query retrieves data on a condition without
  changing records. Update (A), Append (B), and Delete (C) all modify
  stored data.
\item \textbf{C.} Cache is not a permanent backup; it holds copies of data
  that live in RAM. Holding recent data (A), being faster than RAM (B), and
  exploiting locality (D) are all true.
\item \textbf{B.} RAM is volatile and ROM is non-volatile. A reverses the
  pair; C misclassifies both as storage levels; D replaces the volatility
  distinction with unrelated terms.
\item \textbf{C.} MICR reads magnetic ink characters, so this pairing is
  correct. A mislabels the plotter (output) as input; B mislabels the
  scanner (input) as output; D mislabels the sound card (output) as input.
\item \textbf{B.} Statements I and II are correct: registers are fastest,
  and cache is faster than main memory. III is false because RAM is
  volatile. A omits II; C includes false III and omits I; D includes
  false III.
\item \textbf{C.} A digital signature provides authenticity and integrity,
  while encryption provides confidentiality. A swaps in the encryption role;
  B reverses both roles; D claims they are the same process.
\item \textbf{B.} POP3 downloads mail to the local machine while IMAP keeps
  mail synced on the server. A reverses the pair; C invents a printer role;
  D confuses mail protocols with a browser.
\item \textbf{B.} Both statements are true: IPv6 uses 128-bit addresses,
  and HTTP/3 runs over QUIC rather than TCP. But the reason does not explain
  the assertion, so the ``explains'' option (A) is wrong; C and D misjudge
  one statement as false.
\item \textbf{B.} Blank and non-numeric input must be traced branch by
  branch, because the result depends on how the test treats the blank. A
  over-generalises blank handling; C claims empty cells are never accepted;
  D confuses the leading equals sign with branch logic.
\item \textbf{A.} Diagnose the stated bottleneck --- multithreading, memory
  use, or disk activity of that program --- since other programs run
  normally. B blames the clock without evidence; C and D name components
  that do not set execution speed.
\item \textbf{B.} COUNTIFS with range--criterion pairs counts rows where
  all conditions hold. A counts with no criteria; C sums without
  conditions; D averages without criteria.
\end{enumerate}
