\noindent\textbf{Provenance:} All 20 items are original JKSSB-pattern
questions (\textit{[Original]}); none reproduces an official paper item.
\begin{enumerate}[label=\textbf{Q\arabic*.}, leftmargin=*]
\item \textbf{A.} ISP stands for Internet Service Provider. B, C, and D are
  not expansions of the abbreviation.
\item \textbf{A.} RAM is volatile and loses its contents when power goes off.
  ROM (B), the hard disk drive (C), and magnetic tape (D) are all
  non-volatile.
\item \textbf{A.} F5 starts the slide show from the beginning. F7 (B) runs
  spell check; F9 and F2 (C, D) do not start the show.
\item \textbf{A.} A formula must start with \texttt{=}. The other symbols (B,
  C, D) do not mark a formula.
\item \textbf{A.} The bit is the smallest unit of data. A byte (B) is 8 bits;
  a nibble (C) is 4 bits; a kilobyte (D) is far larger.
\item \textbf{A.} Mail Merge combines letters with an address database. Track
  Changes (B) records edits; AutoCorrect (C) fixes typing; Word Count (D)
  counts words.
\item \textbf{A.} \texttt{@} separates the user name from the domain name. B,
  C, and D describe separations \texttt{@} does not perform.
\item \textbf{A.} The BIOS initialises hardware and loads the OS. A device
  driver (B) is software that controls a device; a compiler (C) and an
  assembler (D) translate code.
\item \textbf{A.} POP3 stands for Post Office Protocol version 3. B, C, and D
  are not the correct full form.
\item \textbf{A.} G2C means Government to Citizen. B, C, and D are not the
  recognised expansion.
\item \textbf{C.} A device driver is software, not hardware, so this statement
  is the false one. Cache being faster than RAM (A), RAM being volatile (B),
  and F5 starting the show (D) are all true.
\item \textbf{A.} Speed decreases from registers to cache to main memory (RAM)
  to secondary storage. B swaps the top two levels; C and D scramble the
  order.
\item \textbf{D.} A digitizer tablet captures strokes, so it is an input
  device. A wrongly calls the plotter input (it is output); B wrongly calls
  the sound card input (it is output); C wrongly calls the scanner output (it
  is input).
\item \textbf{A.} Only a Section Break restarts headers and footers. A Page
  Break (B) merely starts a new page; Line Break (C) and Column Break (D) do
  not restart headers.
\item \textbf{A.} POP3 downloads mail to the local machine while IMAP keeps
  mail synced on the server. B reverses the two; C and D are false for both
  protocols.
\item \textbf{A.} Encryption provides confidentiality while a digital
  signature provides authenticity and integrity. B swaps the two roles; C
  conflates them; D is false.
\item \textbf{A.} In IaaS the provider manages infrastructure (networking and
  storage hardware) and the customer manages OS, runtime, apps, and data. B
  reverses the split; C and D misstate the model.
\item \textbf{A.} Statements I and II are correct: IPv6 is 128-bit and BGP is
  inter-domain. III is false because HTTP/3 uses QUIC over UDP, not TCP. B
  includes false III and omits I; C includes false III; D omits II.
\item \textbf{A.} COUNTIFS with two range-criterion pairs counts rows meeting
  both conditions in one step. COUNT (B) counts numbers only; SUM plus COUNT
  (C) and AVERAGE (D) do not apply joint conditions.
\item \textbf{A.} The stated bottleneck is single-threaded execution plus
  memory or disk waits, so threading and memory/disk I/O should be checked
  first. Replacing the CPU (B) ignores the stated waits; C and D are
  unrelated to the bottleneck.
\end{enumerate}
