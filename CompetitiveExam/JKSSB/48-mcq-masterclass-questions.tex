    \item Government to Cloud
  \end{enumerate}
\item \textit{[Original]} Which of the following is \textbf{NOT} true?
  \begin{enumerate}[label=\Alph*.]
    \item Cache is faster than main memory.
    \item RAM is volatile.
    \item A device driver is hardware.
    \item F5 starts a slide show from the beginning.
  \end{enumerate}
\item \textit{[Original]} Which option correctly lists the memory hierarchy in
  order of decreasing speed (fastest first)?
  \begin{enumerate}[label=\Alph*.]
    \item Registers, cache, main memory (RAM), secondary storage
    \item Cache, registers, main memory (RAM), secondary storage
    \item Main memory (RAM), registers, cache, secondary storage
    \item Secondary storage, main memory (RAM), cache, registers
  \end{enumerate}
\item \textit{[Original]} Which pairing is correctly matched?
  \begin{enumerate}[label=\Alph*.]
    \item Plotter --- input device
    \item Sound card --- input device
    \item Scanner --- output device
    \item Digitizer tablet --- input device
  \end{enumerate}
\item \textit{[Original]} A document needs different headers in its two
  halves. Which feature makes this possible?
  \begin{enumerate}[label=\Alph*.]
    \item Section Break
    \item Page Break
    \item Line Break
    \item Column Break
  \end{enumerate}
\item \textit{[Original]} Which statement correctly distinguishes POP3 from
  IMAP?
  \begin{enumerate}[label=\Alph*.]
    \item POP3 downloads mail to the local machine; IMAP keeps mail synced
      on the server.
    \item POP3 keeps mail synced on the server; IMAP downloads and deletes it.
    \item Both POP3 and IMAP permanently delete mail on download.
    \item Neither protocol can be used with a desktop mail client.
  \end{enumerate}
\item \textit{[Original]} Which statement correctly distinguishes encryption
  from a digital signature?
  \begin{enumerate}[label=\Alph*.]
    \item Encryption provides confidentiality; a digital signature provides
      authenticity and integrity.
    \item A digital signature encrypts the body so only the recipient reads
      it; encryption proves the sender.
    \item Both terms mean exactly the same operation.
    \item Encryption works only on paper documents.
  \end{enumerate}
\item \textit{[Original]} Which statement correctly describes the IaaS
  responsibility model?
  \begin{enumerate}[label=\Alph*.]
    \item The provider manages networking and storage hardware; the customer
      manages OS, runtime, apps, and data.
    \item The provider manages the OS and data; the customer manages the
      networking hardware.
    \item The customer manages nothing at all.
    \item The provider manages only the billing.
  \end{enumerate}
\item \textit{[Original]} Evaluate the statements:
  \begin{enumerate}[label=\Roman*.]
    \item IPv6 addresses are 128-bit long.
    \item BGP is an inter-domain routing protocol.
    \item HTTP/3 relies on TCP.
  \end{enumerate}
  \begin{enumerate}[label=\Alph*.]
    \item I and II only
    \item II and III only
    \item I, II, and III
    \item I only
  \end{enumerate}
\item \textit{[Original]} A clerk must count the rows where sales exceed 5000
  \textbf{and} the region is ``North''. Which formula does this in one step?
  \begin{enumerate}[label=\Alph*.]
    \item \texttt{=COUNTIFS(sales,"\textgreater5000",region,"North")}
    \item \texttt{=COUNT(sales,region)}
    \item \texttt{=SUM(sales)+COUNT(region)}
    \item \texttt{=AVERAGE(sales,region)}
  \end{enumerate}
\item \textit{[Original]} An office PC with a quad-core processor runs slowly
  on a task that uses only one thread and repeatedly waits on large files.
  What should be checked first?
  \begin{enumerate}[label=\Alph*.]
    \item Whether the task can use more threads, and whether memory or disk
      I/O is the bottleneck
    \item Replacing the CPU with a higher clock speed at once
    \item Deleting the operating system
    \item Changing the monitor resolution
  \end{enumerate}
